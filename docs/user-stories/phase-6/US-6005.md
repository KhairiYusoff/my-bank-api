# US-6005 — Admin Dashboard — Summary Stats & Quick Access

**Phase:** 6 (addendum)
**Repos:** `my-bank-api`, `my-bank-admin-portal`
**Epic:** Admin Detail Pages
**Status:** 🟡 Ready for Development
**Depends on:** US-6001, US-6002, US-6003 (detail pages must exist for quick-link navigation)

---

## Value Statement

As an admin or banker, I want to land on a dashboard that shows live summary stats, risk signals, financial health, and quick access to items needing attention — so I can immediately understand the state of the system and act without hunting through the sidebar.

---

## Background

The current dashboard is a stub — it shows "Welcome, Admin!" and a logout button. There is nothing actionable on it. An admin logging in has no immediate signal of what needs attention.

All data needed already exists in the three core models (`User`, `Account`, `Transaction`). This story adds a single `/admin/dashboard` endpoint that returns everything in one payload, and replaces the stub with a four-section layout that scrolls naturally.

## Acceptance Criteria

### BE-1: Dashboard Endpoint

1. `GET /admin/dashboard` added to a new `dashboard.routes.js`
2. Allowed roles: `admin`, `banker`
3. Returns:
   ```json
   {
     "success": true,
     "data": {
       "counts": {
         "customers": 1204,
         "accounts": 987,
         "staff": 12,
         "transactionsToday": 3421
       },
       "attention": {
         "pendingApplications": 5,
         "failedTransactionsToday": 2,
         "dormantAccounts": 3
       },
       "financials": {
         "depositsToday": 50200.00,
         "withdrawalsToday": 30100.00,
         "totalPortfolioBalance": 9200000.00
       },
       "recentPendingApplications": [
         { "_id": "...", "name": "Ali Hassan", "email": "ali@email.com", "createdAt": "..." }
       ],
       "recentTransactions": [
         { "_id": "...", "type": "transfer", "amount": 500, "status": "completed", "date": "...", "account": { "accountNumber": "MYB..." } }
       ]
     }
   }
   ```
4. All queries run in a **single `Promise.all`** — never sequential
5. `transactionsToday` / `failedTransactionsToday` / `depositsToday` / `withdrawalsToday` — all scoped to `createdAt >= start of today (UTC)`
6. `dormantAccounts` — `Account.countDocuments({ status: "Dormant" })`
7. `depositsToday` / `withdrawalsToday` — aggregation `$sum` on `amount` where `type` matches and `createdAt` is today
8. `totalPortfolioBalance` — `Account.aggregate` `$sum` of `balance` across all Active accounts
9. `recentPendingApplications` — `applicationStatus === "pending"`, sorted `createdAt desc`, limit 5, fields: `_id name email createdAt`
10. `recentTransactions` — sorted `createdAt desc`, limit 5, populate `account` (field: `accountNumber` only), fields: `_id type amount status date direction account`
11. Activity logged: `activityLogger("VIEW_DASHBOARD", "Staff viewed dashboard")`
12. Route → Controller → Service pattern

### BE-2: Service Method

1. `getDashboardSummary()` in a new `dashboard.service.js`
2. Single `Promise.all([...])` containing all queries — no waterfalling

### FE-1: RTK Query Slice

1. New file: `src/features/dashboard/store/dashboardApi.ts`
2. `getDashboardSummary` query — `GET /admin/dashboard`
3. `providesTags: ["Dashboard"]`
4. `keepUnusedDataFor: 60` (1 min — near-real-time, not live)
5. Export `useGetDashboardSummaryQuery`

### FE-2: Types

1. New file: `src/features/dashboard/types/index.ts`
2. Types: `DashboardCounts`, `DashboardAttention`, `DashboardFinancials`, `DashboardRecentApplication`, `DashboardRecentTransaction`, `DashboardSummary`

### FE-3: Dashboard Page — 4-section layout

#### Header
- Left: "Good morning/afternoon/evening, {name}." (time-aware greeting) + role badge
- Right: current date, formatted (e.g. "Wed, 4 Jun 2026")

#### Row 1 — KPI Cards (4 equal-width MUI Cards)
- Customers · Accounts · Staff · Transactions Today
- Each: coloured icon circle, count (`Typography h4`), "View All" button → list page
- Loading: skeleton placeholder, not spinner

#### Row 2 — Attention Strip
- Three `Chip`-style items in an amber/red tinted `Paper`:
  - ⚠ `{n} Pending Applications` → `/users?applicationStatus=pending`
  - 🔴 `{n} Failed Transactions Today` → `/transactions?status=failed`
  - 💤 `{n} Dormant Accounts` → `/accounts?status=Dormant`
- Hidden entirely if all three counts are zero

#### Row 3 — Financial Snapshot (3 cards)
- ↑ Deposits Today (green accent)
- ↓ Withdrawals Today (red accent)
- Total Portfolio Balance (blue accent)
- Values formatted with `formatCurrency`

#### Row 4 — Side-by-side tables (responsive grid: 2-col desktop, 1-col mobile)
- **Pending Applications table**: Name, Email, Applied date, Action (View button → `/users/:id`)
  - Empty state: `Alert severity="info"` — "No pending applications"
  - "View All" link below table → `/users?applicationStatus=pending`
- **Recent Transactions table**: Date, Type, Amount, Status
  - "View All" link below table → `/transactions`

### FE-4: Register dashboardApi in store

1. Add `dashboardApi.reducer` and `dashboardApi.middleware` to `src/app/store/index.ts`
