# US-9003: Maturity & Renewal Engine
**Status:** ⬜ Planned
**Phase:** 9 — Fixed Deposit Module
**Repo:** `my-bank-api`

## 1. Problem Statement
Fixed Deposits must be managed automatically after their lock period ends. The system must process interest, handle the grace period for withdrawals, and auto-renew accounts that are not closed by the customer.

## 2. User Story
As a **Banking System**, I want **to automate the maturity and renewal of Fixed Deposits**,
So that **interest is credited correctly and accounts are managed according to business rules without manual intervention.**

## 3. Acceptance Criteria
- [ ] Implement daily cron job for FD maturity processing.
- [ ] Upon maturity, FD principal + interest credited to linked account, FD marked `matured`.
- [ ] 7-day grace period enforcement (withdrawals allowed, no auto-renewal).
- [ ] Post-grace period auto-renewal logic (if `autoRenew` is true).

## 4. Technical Tasks
- [ ] Create cron job to check for `maturityDate` daily.
- [ ] Implement interest calculation logic upon maturity.
- [ ] Implement 7-day grace period check logic.
- [ ] Implement auto-renewal service.

## 5. Definition of Done
- [ ] FDs reach maturity and are processed as scheduled.
- [ ] Interest is correctly credited to the linked account.
- [ ] Auto-renewal triggers after the 7-day grace period.
- [ ] All tests pass.
