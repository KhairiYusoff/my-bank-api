# US-9004: FD Settlement at Maturity

**Phase:** 9
**Repos:** `my-bank-api`, `my-bank-customer`
**Status:** ⬜ Planned
**Depends on:** US-9003 (Maturity & Renewal Engine)

---

## Value Statement

As a **Customer**, I want to manually withdraw my principal after my Fixed Deposit matures (during the 7-day grace period), so that I can access my funds and prevent unwanted auto-renewal.

---

## Background

Once an FD matures, US-9003 pays out the interest immediately. The principal remains in the FD during a 7-day "grace period". This story allows the customer to manually trigger the settlement of that principal (transfer to linked account and close FD) before the system automatically renws it on Day 8.

---

## Acceptance Criteria

### BE-1: FD Settlement Endpoint (`POST /api/accounts/:accountNumber/fd-settle`)

**Auth:** Customer (Owner only).

1.  Load Account by `accountNumber`.
2.  Validate:
    -   `accountType === 'fixed_deposit'`
    -   `status === 'active'`
    -   `maturityDate <= now` (Matured).
    -   `now <= maturityDate + 7 days` (Within grace period).
3.  Transfer `principal` amount to `linkedAccount` (Savings/Current).
4.  Create Transaction records for both legs (debit FD, credit Linked).
5.  Set FD `status: 'closed'`.
6.  Log `FD_PRINCIPAL_SETTLEMENT` in `ActivityLog`.

### FE-1: Matured FD Action in Dashboard

-   If FD is matured (`maturityDate <= now`) and within grace period:
    -   Show "Matured" status badge/chip.
    -   Show "Withdraw Principal" button in `AccountDetailsPage` and `BalanceCard`.
-   Clicking "Withdraw Principal" triggers settlement API.
