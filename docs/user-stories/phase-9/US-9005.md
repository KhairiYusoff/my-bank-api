# US-9005: Emergency Early FD Withdrawal

**Phase:** 9
**Repos:** `my-bank-api`, `my-bank-customer`
**Status:** ⬜ Planned
**Depends on:** US-9001 (Unified Provisioning Engine)

---

## Value Statement

As a **Customer**, I want to withdraw my Fixed Deposit early in case of an emergency, even if I forfeit all accrued interest, so that I can access my principal funds when needed.

---

## Background

Business Rule 1.3 states: "Early withdrawal: allowed but forfeits all interest (principal returned only)". Currently, FD withdrawals are blocked until maturity in the `AccountService`. We need to provide a dedicated flow for early redemption.

---

## Acceptance Criteria

### BE-1: Early FD Withdrawal Endpoint (`POST /api/accounts/:accountNumber/fd-withdraw-early`)

**Auth:** Customer (Owner only).

1.  Load Account by `accountNumber`.
2.  Validate:
    -   `accountType === 'fixed_deposit'`
    -   `status === 'active'`
    -   `now < maturityDate` (Early).
3.  Transfer `principal` amount back to `linkedAccount`.
4.  **100% Interest Forfeiture:** No interest is calculated or paid. Any interest already credited (not applicable for early withdrawal as interest is Day 0) is not relevant here as we only return the principal.
5.  Set FD `status: 'closed'`.
6.  Log `FD_EARLY_WITHDRAWAL` in `ActivityLog`.

### FE-1: Early Withdrawal Option & Warning

-   In `AccountDetailsPage` for an active, locked FD:
    -   Show "Early Withdrawal" button.
-   On click, show a Confirmation Dialog:
    -   **Warning:** "Early withdrawal will result in 100% interest forfeiture. You will only receive your original principal of RM X,XXX.XX. This action is irreversible."
    -   Options: "Cancel" / "Proceed with Forfeiture".

---

## Technical Tasks

1.  **API:** Implement `fdWithdrawEarly` in `AccountService`.
2.  **Route:** Register `POST /api/accounts/:accountNumber/fd-withdraw-early`.
3.  **UI:** Update `AccountDetailsPage` to include the early withdrawal button and dialog.
