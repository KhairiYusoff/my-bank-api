## Value Statement

As **The Bank**, I want the system to automatically identify and mark accounts as "dormant" after 12 months of inactivity, blocking all customer-initiated transactions, so that we minimize the risk of unauthorized access and comply with Bank Negara Malaysia (BNM) regulatory requirements for inactive accounts.

---

## Background

An account is considered dormant if there have been no customer-initiated transactions (debit or credit) for a continuous period of 12 months. Benchmarking local Malaysian banks: once an account is dormant, the customer cannot perform any self-service transactions (ATM, online transfers, or deposits). Only system-generated or bank-staff-initiated actions are permitted.

---

## Acceptance Criteria

### BE-1: Dormancy Identification Cron
- Daily cron at **02:00 MYT** (scheduled before FD maturity processing at 03:00) that scans all `active` accounts.
- Scans `Transaction` history for the latest customer-initiated activity.

### BE-2: Dormancy Rule
- If the latest customer-initiated transaction (where `performedBy` is not `null`) is older than 12 months, set `Account.status` to `dormant`.
- If no transactions exist, use `dateOpened` as the baseline.
- Update `statusUpdatedDate` to current timestamp.

### BE-3: Transaction Blocking (Benchmarked)
The following rules apply to `dormant` accounts:
- **BLOCK (403 Forbidden):** All customer-initiated actions (Withdraw, Transfer Out, Deposit/Transfer In via Portal/ATM). 
- **ALLOW:** System actions (Interest credit, Maintenance fee debit, Airdrop by Admin).
- Error message for blocked actions: "Account is dormant. Please visit the nearest branch for reactivation."

### BE-4: Activity Log
- Log `ACCOUNT_DORMANT` in `ActivityLog` when the status is automatically updated by the system.

### BE-5: Notifications
- **Warning:** Send "Dormancy Warning" notification 30 days before the 12-month mark.
- **Activation:** Send "Account Dormant" notification via `notification-service` when status changes.

### FE-1: Dormant Status UI
- Display "Dormant" status badge in `AccountDetailsPage` and `BalanceCard`.
- Use a distinct color (grey) for dormant status.

### FE-2: Action Blocking
- Disable all "Transfer", "Withdraw", and "Deposit" buttons in the customer UI when the account is in `dormant` status.
- Show a clear message: "This account is dormant. Self-service transactions are disabled."
