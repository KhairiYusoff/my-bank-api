# US-7007 — Savings Interest Credited Monthly

**Phase:** 7
**Repos:** `my-bank-api`
**Epic:** Account Type Differentiation
**Status:** ✅ Completed
**Depends on:** US-7001 (account type enum must be correct), US-7006 (node-cron already installed)

---

## Value Statement

As a customer with a Savings account, I want interest credited to my account at the end of each month, so that I benefit from the savings product as described in `business-rules.md`.

---

## Background

**Interest tiers (from `business-rules.md`, annual rate p.a.):**

| Balance Tier | Annual Rate |
|---|---|
| RM 0 – RM 9,999 | 0.50% |
| RM 10,000 – RM 49,999 | 1.00% |
| RM 50,000+ | 1.50% |

- Calculated on **end-of-month balance** (MVP: balance at cron run time)
- Monthly interest = `balance × (annualRate / 100) / 12`
- Minimum balance to earn interest: **RM 1.00** (accounts with balance < RM1 receive no interest)
- Credited on the **last day of the month at 23:59**
- Transaction type: `"interest"`
- `node-cron` is shared with US-7006 (already installed)

---

## Acceptance Criteria

### BE-1: Cron Job File

1. New file: `src/modules/cron/savingsInterest.cron.js`
2. Cron schedule: `"59 23 28-31 * *"` — runs at 23:59 on days 28–31; code checks internally if it is the last day of the month before processing (handles months with 28, 29, 30, or 31 days)
3. Last-day-of-month check inside the job:
   ```js
   const now = new Date();
   const tomorrow = new Date(now); tomorrow.setDate(now.getDate() + 1);
   const isLastDayOfMonth = tomorrow.getDate() === 1;
   if (!isLastDayOfMonth) return; // not the last day — skip silently
   ```
4. The cron job must:
   a. Fetch all `Active` Savings accounts with `balance >= 1`:
      ```js
      const accounts = await Account.find({ status: "Active", accountType: "savings", balance: { $gte: 1 } });
      ```
   b. For each account:
      - Determine tier using the `INTEREST_TIERS` constant (see BE-2)
      - Calculate monthly interest: `Math.round((balance × annualRate / 100 / 12) × 100) / 100` (round to 2 decimal places)
      - If interest rounds to `0.00`: skip (no zero-value transactions)
      - Update `account.balance += interest` and save
      - Create a Transaction document (see BE-3)
      - Send notification (see BE-4)
   c. Errors are caught per-account — one failure does not stop the batch

### BE-2: Interest Tiers Constant

Defined at the top of `savingsInterest.cron.js` (not shared — single use):
```js
const INTEREST_TIERS = [
  { maxBalance: 9999.99,   annualRate: 0.5  },
  { maxBalance: 49999.99,  annualRate: 1.0  },
  { maxBalance: Infinity,  annualRate: 1.5  },
];

function getAnnualRate(balance) {
  return INTEREST_TIERS.find(tier => balance <= tier.maxBalance).annualRate;
}
```

### BE-3: Interest Transaction Document

```js
{
  account: account._id,
  amount: interest,          // calculated monthly interest (2dp)
  type: "interest",
  direction: "credit",
  description: "Monthly savings interest",
  reference: await getNextReference(),
  fee: 0,
  balanceBefore: account.balance - interest,
  balanceAfter: account.balance,
  currency: "MYR",
  channel: "system",
  status: "completed",
  performedBy: null,
  counterpartName: "MyBank",
  counterpartNameRaw: "MyBank",
}
```

### BE-4: Notification

After each interest credit, call `sendNotification()`:
- Type: `"interest_credited"`
- Title: `"Interest Credited"`
- Message: `"RM {interest} interest has been credited to your Savings account {accountNumber}."`
- Recipient: `{ role: "customer", userId: account.user.toString() }`
- Link: `/accounts/${account.accountNumber}`

### BE-5: Register Cron in `server.js`

1. Import below the maintenance fee cron:
   ```js
   require("./modules/cron/savingsInterest.cron");
   ```
2. Add startup log: `console.log("[Cron] Savings interest job registered")`

### BE-6: Error Handling

- Entire run wrapped in `try/catch`
- Errors logged: `console.error("[Cron] Savings interest job failed:", err.message)`
- Per-account errors caught and logged individually — batch continues on failure
- No server crash on cron error

## Out of Scope

- Daily balance accumulation for more accurate interest calculation (Phase 9+)
- Interest calculation for Fixed Deposit accounts (Phase 9 — different mechanism: credited at maturity, not monthly)
- Current and Business accounts — no interest applies
- Tax withholding on interest — not in MVP
