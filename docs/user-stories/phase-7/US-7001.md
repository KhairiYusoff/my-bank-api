# US-7001 — Transfer & Withdrawal Rules Enforced

**Phase:** 7
**Repos:** `my-bank-api`
**Epic:** Account Type Differentiation
**Status:** 🟡 Ready for Development
**Depends on:** Phase 6 complete

---

## Value Statement

As a system, I want to enforce the correct transfer and withdrawal rules for each account type — including per-type limits, daily caps, overdraft-aware balance checks, and blocks on Fixed Deposit accounts and inactive accounts — so that business rules defined in `business-rules.md` are actually enforced in code, not just documented.

---

## Background

Currently `transferFunds()` and `withdraw()` perform only a single naive balance check:

```js
if (fromAccount.balance < amount) { ... }  // no overdraft
```

This means:
- Overdraft accounts can be drained past `-overdraftLimit` (wrong — should allow up to that limit)
- Accounts with `overdraftLimit > 0` never get the benefit of the overdraft
- There is no per-type max single transfer cap
- There is no daily cumulative transfer cap
- FD accounts can send and receive transfers (should be blocked)
- Inactive/dormant accounts are not blocked
- Self-transfer is not blocked
- No minimum amount enforced

Additionally, the `Account.accountType` enum is `["Savings", "Checking", "Business"]` (Title Case, wrong code for Current, missing Fixed Deposit) — this must be corrected before any type-based rule can be written reliably.

## Acceptance Criteria

### BE-1: Account Model — Enum Fix + Migration

1. `accountType` enum in `Account.js` updated from `["Savings", "Checking", "Business"]` to:
   ```js
   enum: ["savings", "current", "business", "fixed_deposit"]
   ```
2. `overdraftLimit` default set to `0` (currently has no default):
   ```js
   overdraftLimit: { type: Number, default: 0 }
   ```
3. New migration script: `scripts/migrateAccountTypes.js`
   - Connects to MongoDB using env `MONGODB_URI`
   - Runs once: updates all Account documents:
     - `"Savings"` → `"savings"`
     - `"Checking"` → `"current"`
     - `"Business"` → `"business"`
   - Logs count of updated documents
   - Safe to re-run (idempotent — already-lowercase values are left unchanged)
4. All callers of `createAccount()` in `account.service.js` must send lowercase type strings — update `onboarding.service.js` `accountTypeMap` mapping accordingly:
   ```js
   const accountTypeMap = { savings: "savings", current: "current", business: "business" };
   ```
5. Migration must be run manually once on the live DB before deploying this story — document in PR description

### BE-2: Transfer Rules — `transferFunds()` in `transaction.service.js`

Add the following validations in order. All checks run **before** the Mongoose session opens (fail fast):

| # | Check | Error message | HTTP |
|---|---|---|---|
| 1 | `amount < 1` | "Minimum transfer amount is RM1.00" | 400 |
| 2 | `fromAccountNumber === toAccountNumber` | "Cannot transfer to the same account" | 400 |
| 3 | `fromAccount.status !== "Active"` | "This account is not active and cannot process transfers" | 400 |
| 4 | `fromAccount.accountType === "fixed_deposit"` | "Fixed Deposit accounts cannot send transfers" | 400 |
| 5 | `toAccount.accountType === "fixed_deposit"` | "Fixed Deposit accounts cannot receive transfers" | 400 |
| 6 | `amount > MAX_SINGLE_TRANSFER[fromAccount.accountType]` | "Transfer amount exceeds the RM{limit} single transfer limit for this account type" | 400 |
| 7 | `dailyTotal + amount > DAILY_LIMIT[fromAccount.accountType]` | "This transfer would exceed the RM{limit} daily transfer limit for this account type" | 400 |
| 8 | `fromAccount.balance + fromAccount.overdraftLimit < amount` | "Insufficient funds" | 400 |

**Type limits constant** (define at top of `transaction.service.js`):
```js
const MAX_SINGLE_TRANSFER = { savings: 5000, current: 10000, business: 20000 };
const DAILY_TRANSFER_LIMIT = { savings: 10000, current: 20000, business: 50000 };
```

**Daily total query** (check #7) — runs before session, after account is fetched:
```js
const startOfDay = new Date(); startOfDay.setHours(0, 0, 0, 0);
const endOfDay   = new Date(); endOfDay.setHours(23, 59, 59, 999);
const dailyAgg = await Transaction.aggregate([
  { $match: { account: fromAccount._id, type: "transfer", direction: "debit",
              createdAt: { $gte: startOfDay, $lte: endOfDay } } },
  { $group: { _id: null, total: { $sum: "$amount" } } }
]);
const dailyTotal = dailyAgg[0]?.total ?? 0;
```

**Balance check** (check #8):
```js
const available = fromAccount.balance + (fromAccount.overdraftLimit ?? 0);
if (available < amount) { ... }
```

### BE-3: Withdrawal Rules — `withdraw()` in `account.service.js`

Add the following validations in order. All checks run **before** the Mongoose session opens:

| # | Check | Error message | HTTP |
|---|---|---|---|
| 1 | `amount < 10` | "Minimum withdrawal amount is RM10.00" | 400 |
| 2 | `account.status !== "Active"` | "This account is not active and cannot process withdrawals" | 400 |
| 3 | `account.accountType === "fixed_deposit"` | "Fixed Deposit withdrawals are not permitted until the account matures" | 400 |
| 4 | `account.balance + account.overdraftLimit < amount` | "Insufficient funds" | 400 |

**Balance check** (same pattern as transfers):
```js
const available = account.balance + (account.overdraftLimit ?? 0);
if (available < amount) { ... }
```

Note: the existing check `if (account.balance < amount)` on line 328 of `account.service.js` must be **replaced** with the overdraft-aware check above.

### BE-4: Migration Script Format

`scripts/migrateAccountTypes.js`:
```js
// Usage: node scripts/migrateAccountTypes.js
require("dotenv").config();
const mongoose = require("mongoose");
const Account = require("../src/shared/models/Account");

const TYPE_MAP = { Savings: "savings", Checking: "current", Business: "business" };

async function run() {
  await mongoose.connect(process.env.MONGODB_URI);
  for (const [from, to] of Object.entries(TYPE_MAP)) {
    const result = await Account.updateMany({ accountType: from }, { $set: { accountType: to } });
    console.log(`${from} → ${to}: ${result.modifiedCount} updated`);
  }
  await mongoose.disconnect();
}

run().catch((err) => { console.error(err); process.exit(1); });
```
