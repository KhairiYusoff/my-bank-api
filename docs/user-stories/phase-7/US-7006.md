# US-7006 — Monthly Maintenance Fee Deducted Automatically

**Phase:** 7
**Repos:** `my-bank-api`
**Epic:** Account Type Differentiation
**Status:** ✅ Completed
**Depends on:** US-7001 (account type enum must be correct), US-7008 (notification trigger reused from this cron)

---

## Value Statement

As the bank, I want to automatically deduct a monthly maintenance fee from accounts whose average balance falls below the minimum threshold, so that the fee structure defined in `business-rules.md` is enforced without manual intervention.

---

## Background

**Fee rules (from `business-rules.md`):**

| Account Type | Monthly Fee | Threshold (avg monthly balance) |
|---|---|---|
| `savings` | RM 5.00 | < RM 1,000 |
| `current` | RM 8.00 | < RM 2,000 |
| `business` | RM 15.00 | < RM 5,000 |
| `fixed_deposit` | RM 0.00 | Never charged |

- Deducted on the **1st of each month** at 00:01
- If account balance is less than the fee amount: **fee is waived** that month (not deducted into negative)
- Fee transactions appear in transaction history as `type: "fee"`
- Cron library: `node-cron` (not currently installed — must be added)

For MVP, average monthly balance is approximated as the **current balance at cron run time**. Proper average calculation (daily balance sum / days in month) is a Phase 9+ improvement.

## Acceptance Criteria

### BE-1: Install `node-cron`

1. Run `npm install node-cron` in `my-bank-api`
2. Types are included in the package — no `@types/node-cron` needed (it ships its own types)

### BE-2: Cron Job File

1. New file: `src/modules/cron/maintenanceFee.cron.js`
2. Cron schedule: `"1 0 1 * *"` — 00:01 on the 1st of every month
3. The cron job must:
   a. Fetch all `Active` Savings, Current, and Business accounts (FD is excluded):
      ```js
      const accounts = await Account.find({
        status: "Active",
        accountType: { $in: ["savings", "current", "business"] },
      });
      ```
   b. For each account:
      - Determine the applicable fee and threshold from the `FEE_RULES` constant (see BE-3)
      - Check if `account.balance < threshold` (below maintenance minimum)
      - If below threshold AND `account.balance >= fee`: deduct fee, create Transaction
      - If below threshold AND `account.balance < fee`: waive fee, log `console.warn`
      - If at or above threshold: no action
   c. All DB writes are individual (not batched in one session) — if one account fails, others still process; errors are logged and processing continues
4. Each fee deduction:
   - Updates `account.balance -= fee` and saves
   - Creates a Transaction document:
     ```js
     {
       account: account._id,
       amount: fee,
       type: "fee",
       direction: "debit",
       description: "Monthly maintenance fee",
       reference: await getNextReference(),
       fee: 0,
       balanceBefore: account.balance + fee,
       balanceAfter: account.balance,
       currency: "MYR",
       channel: "system",
       status: "completed",
       performedBy: null,
       counterpartName: "MyBank",
       counterpartNameRaw: "MyBank",
     }
     ```
   - Sends notification (US-7008 utility — see BE-4)

### BE-3: Fee Rules Constant

Defined at the top of `maintenanceFee.cron.js` (not in a shared file — single use):
```js
const FEE_RULES = {
  savings:  { fee: 5,  threshold: 1000 },
  current:  { fee: 8,  threshold: 2000 },
  business: { fee: 15, threshold: 5000 },
};
```

### BE-4: Notification Trigger

After a fee is deducted, call `sendNotification()` from `notification.service.js`:
- Type: `"fee_deducted"`
- Title: `"Maintenance Fee Deducted"`
- Message: `"RM {fee}.00 monthly maintenance fee has been deducted from account {accountNumber}. Maintain a balance of RM {threshold} or above to waive this fee."`
- Recipient: `{ role: "customer", userId: account.user.toString() }`
- Link: `/accounts/${account.accountNumber}`

After checking balance falls below threshold (even if fee is waived), also call the threshold notification utility from US-7008 (`notifyBelowThreshold`).

### BE-5: Register Cron in `server.js`

1. Import the cron module at the top of `server.js`:
   ```js
   require("./modules/cron/maintenanceFee.cron");
   ```
2. The import registers the cron job automatically — `node-cron` starts it when the module loads
3. Add a startup log: `console.log("[Cron] Maintenance fee job registered")`

### BE-6: Error Handling

- The cron job wraps the entire run in `try/catch`
- Errors are logged: `console.error("[Cron] Maintenance fee job failed:", err.message)`
- Individual account failures are caught per-account inside a try/catch — one failure does not stop the batch
- No crash on cron error — the server continues running
