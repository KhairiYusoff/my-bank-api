# US-8003: Role-Based Access Control (RBAC) Enforcement
**Status:** ✅ Completed
**Phase:** 8 — Role Expansion
**Repo:** `my-bank-api`, `my-bank-admin-portal`

**Source of Truth:** All UI guards, API filters, and navigation visibility for this story **MUST** strictly adhere to the RBAC Matrix and Sensitive Data Exposure Matrix defined in `docs/engineering/security/authorization.md`.

## 1. Problem Statement
With the addition of the `auditor` role, we must ensure that all administrative actions in the admin portal are strictly limited by the user's role. Currently, the UI may still show options to unauthorized roles, and while the backend may have some protection, it needs a comprehensive, consistent enforcement layer.

## 2. User Story
As an **Admin/Banker/Auditor**,
I want **the portal to only show me functions I am authorized to perform**,
So that **the system is secure and I do not accidentally access restricted modules.**

## 3. Acceptance Criteria
- [x] Sidebar navigation items are dynamically filtered based on the user's role.
- [x] Routes are protected with guards; unauthorized users attempting to navigate to forbidden pages are redirected to a new 403 page.
- [x] Dashboard cards are restricted:
    - Banker: No "Staff" or "Airdrop" access.
    - Auditor: Read-only access (e.g., Audit logs, customer profiles), no "Staff" or "Airdrop" mutation capabilities.
- [x] Backend `getDashboardSummary` API restricts sensitive data (e.g., total staff count) based on role.
- [x] A new `ForbiddenPage` component is created for unauthorized access attempts.

## 4. Technical Tasks
- [x] Create `ForbiddenPage` component.
- [x] Implement `RouteGuard` for navigation.
- [x] Filter `navItems` array in `AdminLayout` based on roles.
- [x] Update dashboard UI components to conditionally hide sensitive cards.
- [x] Update `dashboardApi` or controller to enforce data visibility on the backend.

## 5. Definition of Done
- [x] Users can only see navigation items they are authorized to use.
- [x] Unauthorized navigation attempts are correctly redirected to the 403 Forbidden page.
- [x] Dashboard sensitive data is hidden for non-admin/non-authorized roles.
- [x] All tests pass.
