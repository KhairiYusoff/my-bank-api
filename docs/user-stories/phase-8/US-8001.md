# US-8001: Add Auditor Role

**Status:** ✅ Completed
**Phase:** 8 — Role Expansion
**Repo:** `my-bank-api`, `my-bank-admin-portal`

---

## 1. Problem Statement
To ensure better security, fraud detection, and regulatory compliance, the system requires a dedicated read-only role for internal auditors. Currently, the UI may still show options to unauthorized roles, and while the backend may have some protection, it needs a comprehensive, consistent enforcement layer. The role was added to the DB, but implementation is incomplete because it cannot be assigned to new staff.

## 2. User Story
As an **Internal Auditor**,  
I want **read-only access to all banking data, unmasked transaction details, and full system activity logs**,  
So that **I can conduct thorough investigations and audits without any risk of accidentally or intentionally altering data.**
